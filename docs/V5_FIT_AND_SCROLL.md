# V5 착장·화면 안내

## 의상 규칙

- 원피스는 상의, 치마, 바지를 함께 선택할 수 없습니다.
- 상의는 원피스를 해제합니다. 치마/바지는 원피스와 서로 다른 하의를 해제합니다.
- 같은 선택을 다시 누르면 머리를 제외하고 벗습니다. 처음부터는 기본 머리·신발만 둡니다.
- 마법 코디는 이전 옷에 누적하지 않고 한 벌을 새로 고릅니다.
- 오래된 충돌 저장값은 원피스를 우선하고, 원피스가 없으면 바지를 우선합니다. 사진첩 항목은 바꾸지 않습니다.

## 그림과 표시

전신 PNG는 1086×1448, 런타임 viewBox는 360×480입니다. 크기 비율이 같더라도 목선·어깨·허리·발 위치가 맞는 것은 아닙니다. 착용 위치는 캐릭터의 기준점과 실제 합성 화면으로 확인해야 합니다. 이번 조정은 girl01의 임시 SVG 상의·하의 위치와 모자·액세서리 위치를 기준점에 맞췄고, 다른 캐릭터의 SVG 좌표는 유지합니다. girl01 전용 래스터 파츠는 다른 캐릭터에 그대로 사용하지 않고 기존 SVG로 표시합니다. 새로 추가한 `hair_05`와 교체한 `dress_05`는 `assets/assetRegistry.js`에서 경로를 매핑하며, 픽셀 동일한 WebP 런타임 파일도 제공합니다.

## 조작

- 카테고리 및 아이템 레일은 터치 스와이프와 좌우 화살표를 지원합니다.
- 카테고리 레일의 위치와 카테고리별 아이템 위치는 선택 후 재렌더에도 보존됩니다. 현재 항목과 같은 버튼으로 키보드 초점을 복구합니다.
- 기본 세로 화면은 화면 안에 맞추고, 높이 500 CSS px 이하에서는 꾸미기 페이지를 세로로 스크롤할 수 있습니다.
- 마지막 카드까지 이동 가능한지는 실제 뷰포트에서 별도로 확인합니다. 아이템 파일 검사만으로 착용/레이아웃 합격을 의미하지 않습니다.
